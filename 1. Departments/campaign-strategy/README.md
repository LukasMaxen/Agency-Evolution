# Campaign Strategy

**Owner:** Kasper Zacho

## What This Department Does

Defines the offer, messaging, and campaign angles for each client. Every client is different — their offer, target audience, tone, and value proposition must be kept completely separate to avoid mixing up messaging across workspaces.

## IMPORTANT: Client Isolation

Each client has their own file in this folder. Never apply one client's offer, angle, or positioning to another client. When working on campaign strategy, always open the specific client file first.

## Core Responsibilities

- Define and refine the core offer and value proposition per client
- Develop messaging angles and A/B test variations
- Map the target audience and decision-maker profile per client
- Ensure campaign messaging stays aligned with each client's goals

## AI Can Help With

- Generating new messaging angles based on client offer
- A/B testing subject lines and opening lines
- Rewriting campaign copy to improve reply rates
- Identifying positioning gaps or objections not currently addressed

## Workflow

```
Client brief → Offer definition → Messaging angles → Campaign copy → Hand off to campaign-management/
```
