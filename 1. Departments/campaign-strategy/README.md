# Campaign Strategy

**Owner:** Kasper Zacho

## How This Works

Campaign strategy is a **skill**, not a per-client folder. This department describes HOW to build strategy. The client-specific context (offer, ICP, angles, what's working) lives in `clients/[client-slug].md`.

When building a campaign for a specific client:
1. Read `clients/[client-slug].md` for their offer, ICP, tone, and history
2. Apply the methodology from this folder
3. Write copy and angles back into the client file under "Campaign Strategy"

## Core Responsibilities

- Develop messaging angles based on client offer and ICP
- Write and iterate on cold email sequences
- A/B test subject lines and opening lines
- Track what works across clients and apply learnings broadly

## AI Can Help With

- Generating new messaging angles from a client brief
- Writing subject lines and opening lines at scale
- A/B testing copy variants
- Analysing reply patterns to identify what's resonating

## Methodology

### Angle Development

A strong angle answers one of these:
- **Pain:** What problem does this client solve that the prospect feels right now?
- **Opportunity:** What upside are they missing out on?
- **Social proof:** Who else like them has gotten results?
- **Curiosity:** What's the one thing they don't know that changes everything?

Start with 2–3 angles. Run each for sufficient sends. Kill the lowest performer. Iterate.

### Sequence Structure

- **Step 1:** Core pitch — short, one clear ask
- **Step 2:** Follow-up — different angle or add proof
- **Step 3:** Bump — short, low friction
- **Step 4+:** Value add or final close

### Subject Line Rules

- Under 50 characters
- No all-caps, excessive punctuation, or spam trigger words
- Best performers: curiosity, personalisation, direct ask
- Always A/B test subject lines on first campaigns

### Opening Line Rules

- First line must hook — don't start with "I" or "My name is"
- Personalised > generic always
- Reference something specific: their role, company, a recent event
