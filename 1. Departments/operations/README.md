# Operations

**Owner:** Lukas Maxen

## What This Department Does

Covers everything that keeps the business running internally — the AI Reply Desk tech stack, team coordination, git workflow, AI tooling framework, and infrastructure.

## Core Responsibilities

- Maintain and improve the AI Reply Desk (Next.js 16 dashboard)
- Manage the tech infrastructure (Vercel, Hetzner PostgreSQL, EmailBison, Calendly, Anthropic)
- Define and enforce git workflow for the team
- Build and document new AI automations as we expand the Business OS
- Onboard new team members to the repo and tooling

## AI Can Help With

- Building new features in the AI Reply Desk
- Writing and debugging API routes, DB queries, and integrations
- Designing new automations for any department
- Diagnosing infrastructure or deployment issues
