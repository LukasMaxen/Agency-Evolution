# Campaign Management

**Owner:** Kasper Zacho

## What This Department Does

Runs the day-to-day execution of cold email campaigns across all 15+ client workspaces on EmailBison. Takes strategy from campaign-strategy/ and enriched lists from lead-enrichment/ and turns them into live, sending campaigns.

## Core Responsibilities

- Set up and configure campaigns in EmailBison per client
- Build email sequences and manage sending schedules
- Monitor campaign performance (open rates, reply rates, bounce rates)
- Make in-flight adjustments to improve performance
- Coordinate with reply-management/ when leads start responding

## AI Can Help With

- Writing and improving email sequences
- Diagnosing low reply rates and suggesting fixes
- Generating A/B variants for sequence steps
- Summarising campaign performance across clients

## Workflow

```
Enriched list + strategy → EmailBison campaign setup → Sequences live → Monitor → Hand off replies to reply-management/
```
