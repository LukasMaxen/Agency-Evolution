# Campaign

**Owner:** Kasper Zacho

## What This Department Does

Covers the full campaign lifecycle — from angle development and script writing to EmailBison setup, sequence management, performance monitoring, and reply handoff.

Campaign strategy (the HOW) lives here. Client-specific context (offer, ICP, angles, what's working) lives in `clients/[client-slug].md`.

## Core Responsibilities

- Develop messaging angles based on client offer and ICP
- Write and iterate on cold email sequences (steps 1–3)
- A/B test subject lines and opening lines
- Set up and configure campaigns in EmailBison per client
- Monitor performance (open rates, reply rates, bounce rates)
- Make in-flight adjustments to improve performance
- Hand off interested replies to reply-management/

## AI Can Help With

- Writing and improving email sequences
- Generating A/B variants for steps, subject lines, and openers
- Diagnosing low reply rates and suggesting fixes
- Running the lead monitoring check
- Summarising campaign performance across clients

## Workflow

```
Read clients/[slug].md → Define angles → Write sequences → Load into EmailBison → Monitor → Hand off replies
```
