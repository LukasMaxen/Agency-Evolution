# Leads

**Owners:** Sunny Newar (enrichment) + Sunny Newar + Kasper Zacho (sourcing)

## What This Department Does

Covers the full lead pipeline from raw list sourcing through enrichment, scoring, and handoff to the campaign team. Every client engagement starts here.

## Core Responsibilities

**Sourcing**
- Define the Ideal Customer Profile (ICP) for each client
- Source contact lists from Apollo, LinkedIn Sales Nav, and other channels
- Verify list quality before passing to enrichment

**Enrichment**
- Verify and validate email addresses (reduce bounce rates)
- Enrich contacts with job title, company size, revenue, and other relevant data
- Score and prioritise leads based on ICP fit before passing to campaign

## Workflow

```
Client brief → ICP definition → Source lists (Apollo/LinkedIn) → Quality check → Email verification → Data enrichment → Lead scoring → Hand off to campaign/
```

## AI Can Help With

- Generating ICP definitions from a client brief
- Writing Boolean search strings for LinkedIn/Apollo/Clay
- Scoring and filtering raw lead lists against ICP criteria
- Writing enrichment prompts for Clay or Apollo
- Generating personalisation snippets from enriched data
- Identifying missing data fields and suggesting sources
