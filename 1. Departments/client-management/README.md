# Client Management

**Owner:** Lukas Maxen

## What This Department Does

Manages the relationship and operational setup for each of our 15+ clients. Covers onboarding, workspace configuration, per-client context, and client communications.

## Core Responsibilities

- Onboard new clients (DB setup, webhook registration, profile creation)
- Maintain up-to-date client profiles (offer, tone, Calendly links, contacts)
- Track client workspace status and health
- Handle client communications and reporting

## AI Can Help With

- Drafting client update emails or reports
- Generating onboarding checklists for new clients
- Summarising activity across a client's workspace
- Flagging anomalies in client campaign data

## Workflow

```
New client signed → Onboarding checklist → DB + EmailBison setup → Profile filled in → Campaign strategy briefed → Live
```
