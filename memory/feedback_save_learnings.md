Always save learnings to the correct file in the repo as they are learned — do not wait until asked.

Split correctly:
- **SKILL files** — process rules, steps, how to execute, what to check before acting
- **CONTEXT files** — tone rules, patterns, objection handling, scenario examples
- **Client files** — anything client-specific (Calendly links, exceptions, templates, offer details)
- **Memory** — things that need to persist across conversations but aren't repo content

**Why:** The repo is the source of truth for the team and for future AI sessions. Memory alone is not enough.

**How to apply:** After every correction or new rule learned in a conversation, save it to the right file immediately.
