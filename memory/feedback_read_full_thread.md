Before drafting any reply, check what has already been sent to that lead. Do not repeat stats, stories, links, or value props that were already in the thread.

**Why:** Repeating yourself looks sloppy and breaks trust with the lead.

**How to apply:** Query sent_emails or the thread history for that lead before writing. Adapt the reply to only include information that is new to them.
