Always end every reply with `{SENDER_EMAIL_SIGNATURE}` on its own line. Never write "Best," or "Best regards," or any name before it. The variable includes the full signature.

Always use proper paragraph spacing — a blank line between each paragraph. Never run lines together into one block. Each sentence group that belongs together is its own paragraph, separated by a blank line.

**Why:** Signature variable is handled by EmailBison. Running text together looks broken in email clients.

**How to apply:** Every single reply across all clients, no exceptions.
