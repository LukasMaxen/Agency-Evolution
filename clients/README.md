# Clients

One file per client. Each file is the single source of truth for everything about that client — offer, ICP, campaign strategy, reply guidelines, FU templates, Slack/email history, and campaign notes.

**Before any client task, open their file first.**

When onboarding a new client, copy `_template.md`, rename it to `[slug].md`, and fill it in following `departments/client-management/onboarding.md`.
